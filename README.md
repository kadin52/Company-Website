# Lots Plumbing Website

A responsive business website built for Lots Plumbing, an Orange County plumbing and repiping company.

This project modernizes the company’s existing website with responsive layouts, improved navigation, contact forms, SEO-friendly routes, and a real-time customer support chat.

## Live Website

[https://www.lotsplumbing.com](https://www.lotsplumbing.com)

## Technologies Used

- **Next.js 16** — App Router, layouts, routing, image optimization, redirects, and metadata
- **React 19** — Reusable components, state management, effects, and interactive interfaces
- **TypeScript** — Static typing for components, props, messages, and event handlers
- **Tailwind CSS 4** — Responsive styling and mobile-friendly layouts
- **Firebase Authentication** — Authentication for protected support pages
- **Cloud Firestore** — Real-time chat messages, chat sessions, timestamps, and unread status
- **React Rnd** — Draggable and resizable chat windows
- **React Slick** — Homepage image carousel
- **FormSubmit** — Contact-form email delivery
- **Lucide React** — Interface icons
- **Vercel** — Production deployment and custom-domain hosting
